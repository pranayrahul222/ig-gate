# Security

IG Gate has no API keys and no server. Do not commit passwords, tokens, keystores, or `local.properties`.

The app does not use an Accessibility Service. It cannot read the screen or tap buttons in other apps. Internet is used only to open Instagram and YouTube pages inside this app. Cleartext traffic is blocked. Cloud backup of app data is off.

Report a security problem through GitHub private vulnerability reporting on this repository. Do not open a public issue for a security flaw.
